# Module 6: Evaluation and Staying Current

This module covers evaluation, i.e., the practice of deciding whether an AI-assisted result is correct before anyone relies on it. An analyst who accepts a generated answer without checking it has moved the work from the model to the reader, since someone must still confirm that the numbers hold. Three checks carry most of the weight in ordinary analytics work: a direct check of the result against the data it claims to describe, a held-out example whose answer is known in advance, and a comparison against a baseline produced by a simpler method. A held-out example is useful because it tests the procedure rather than the single case, and a baseline is useful because it shows whether the AI-assisted approach improved anything at all. The habit we want is small and repeatable, i.e., every result receives at least one check that could have failed.

Staying current is the second half of the module, and it presents a different problem, since the field changes weekly while the hours available for reading do not expand to match. The goal is not to read everything but to build a small routine that surfaces the changes that would alter how a student works. We recommend one daily source read in a few minutes, one weekly source read more carefully, and one deeper source for the weeks when a topic warrants the time. After this module, a student should be able to name a check for an AI-assisted result, run that check, and say where a change in the tools they depend on would first become visible. None of this replaces domain judgment, which remains the analyst's responsibility no matter how the result was produced.

The resources for this module fill those three slots, with one daily source, one weekly source, and several that reward slower reading. TLDR AI sends a free daily email of the most interesting AI stories and breakthroughs every weekday, which makes it the natural choice for the daily slot, while The Batch delivers weekly AI news and insights by email and covers what matters in AI right now. Sebastian Raschka (Ahead of AI) writes about machine learning and AI research for more than 200,000 researchers and practitioners and wrote Build a Large Language Model (From Scratch), so the newsletter suits a student who wants to understand why a system behaves as it does. Simon Willison's Weblog, written by the creator of the open source tool Datasette and running since 2002, covers AI, LLMs, web engineering, open source, data science, SQLite, and Python, and Willison states that no compensation is received for writing about specific topics. The TWIML AI Podcast describes its content as giving practitioners, innovators, and leaders an inside look at the present and future of machine learning and AI technologies, which fits listening time rather than reading time.
