# Learning Path

The learning path sequences seven biweekly enrichment modules across the semester. Each module names a topic, states what a student should be able to do afterward, and points at a small number of resources from the catalog. Module 1 has been delivered, and the remaining modules are planned. Their topics may change as the semester proceeds and as the tools themselves change, which is one reason this site is refreshed rather than written once.
