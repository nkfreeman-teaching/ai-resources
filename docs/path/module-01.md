# Module 1: Agentic Tools and Student Offers

This module introduces the distinction between ordinary use of an AI assistant in a browser and agentic use, and it points students at the tools that offer free or reduced-cost access. Ordinary use refers to a conversation in which a person types a question, reads the answer, and decides what to do next. Agentic use refers to a mode of work in which the assistant is given a goal and a set of tools (e.g., a file system, a terminal, or a web browser) and carries out a sequence of actions toward that goal, reporting back when the work is done or when a decision requires a person. The difference is not the underlying model but the harness around it, i.e., the software that lets the model read, write, run, and check its own work. An analyst who learns to work in the agentic mode can delegate an entire data-cleaning task, whereas an analyst in the browser mode can only ask for the code and run it by hand.

Several vendors provide students with free or discounted access to their paid tiers, and the entries below record the terms as verified on the date shown. These offers change by semester, so we recommend confirming the current terms on the vendor page before enrolling. The remainder of this module lists the resources we discussed in the first session.
